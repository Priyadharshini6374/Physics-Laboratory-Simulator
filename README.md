# 🔬 Physics Laboratory Simulator

An interactive, web-based physics laboratory that allows students to explore physics experiments through digital simulations.

## 📌 Project Overview

The Physics Laboratory Simulator provides a virtual environment where users can change experiment parameters, observe physical behavior, and understand physics concepts without requiring physical laboratory equipment.

## ✨ Features

* **Projectile Motion** — Explore how velocity, launch angle, and gravity affect projectile movement.
* **Pendulum** — Observe pendulum motion by adjusting its length and initial angle.
* **Collision** — Explore collisions by changing object masses and velocities.
* **Friction** — Study how mass, velocity, and friction coefficient affect motion.
* **Spring and Mass** — Investigate spring motion by adjusting mass, spring constant, and displacement.
* **Free Fall** — Observe falling motion by changing height and gravity.

### Interactive Controls

* Adjust experiment parameters.
* Start, pause, and reset simulations.
* View simulation animations and graphs.
* Observe calculated experiment results.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* HTML Canvas for visual simulations and graphs

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select an experiment and modify its parameters.
5. Start the simulation and observe the results.

## 🎯 Project Objective

To make physics concepts easier to understand through interactive visualizations, parameter adjustments, and simulated experiments.
